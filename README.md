## What I'm working on now

### AgentSats – Agent Wallet Governance Layer

`AgentSats` is a framework that sits between **AI agents** and **Bitcoin/Lightning
infrastructure**:

- SDK for agents (e.g. `pay_if_required()`, `pay_invoice()`, `get_balance()`)
- Policies for budgets, limits, allowed targets and human-in-the-loop rules
- Non-custodial: keys & funds stay with the user/organisation
- Designed for agentic workflows, Pay-per-API and machine payments

> Status: early-stage / exploration. Expect rapid iteration and breaking changes.
